1""" 

2Normalization. 

3 

4Wikipedia: https://en.wikipedia.org/wiki/Normalization 

5Normalization is the process of converting numerical data to a standard range of values. 

6This range is typically between [0, 1] or [-1, 1]. The equation for normalization is 

7x_norm = (x - x_min)/(x_max - x_min) where x_norm is the normalized value, x is the 

8value, x_min is the minimum value within the column or list of data, and x_max is the 

9maximum value within the column or list of data. Normalization is used to speed up the 

10training of data and put all of the data on a similar scale. This is useful because 

11variance in the range of values of a dataset can heavily impact optimization 

12(particularly Gradient Descent). 

13 

14Standardization Wikipedia: https://en.wikipedia.org/wiki/Standardization 

15Standardization is the process of converting numerical data to a normally distributed 

16range of values. This range will have a mean of 0 and standard deviation of 1. This is 

17also known as z-score normalization. The equation for standardization is 

18x_std = (x - mu)/(sigma) where mu is the mean of the column or list of values and sigma 

19is the standard deviation of the column or list of values. 

20 

21Choosing between Normalization & Standardization is more of an art of a science, but it 

22is often recommended to run experiments with both to see which performs better. 

23Additionally, a few rules of thumb are: 

24 1. gaussian (normal) distributions work better with standardization 

25 2. non-gaussian (non-normal) distributions work better with normalization 

26 3. If a column or list of values has extreme values / outliers, use standardization 

27""" 

28from statistics import mean, stdev 

29 

30 

31def normalization(data: list, ndigits: int = 3) -> list: 

32 """ 

33 Return a normalized list of values. 

34 

35 @params: data, a list of values to normalize 

36 @returns: a list of normalized values (rounded to ndigits decimal places) 

37 @examples: 

38 >>> normalization([2, 7, 10, 20, 30, 50]) 

39 [0.0, 0.104, 0.167, 0.375, 0.583, 1.0] 

40 >>> normalization([5, 10, 15, 20, 25]) 

41 [0.0, 0.25, 0.5, 0.75, 1.0] 

42 """ 

43 # variables for calculation 

44 x_min = min(data) 

45 x_max = max(data) 

46 # normalize data 

47 return [round((x - x_min) / (x_max - x_min), ndigits) for x in data] 

48 

49 

50def standardization(data: list, ndigits: int = 3) -> list: 

51 """ 

52 Return a standardized list of values. 

53 

54 @params: data, a list of values to standardize 

55 @returns: a list of standardized values (rounded to ndigits decimal places) 

56 @examples: 

57 >>> standardization([2, 7, 10, 20, 30, 50]) 

58 [-0.999, -0.719, -0.551, 0.009, 0.57, 1.69] 

59 >>> standardization([5, 10, 15, 20, 25]) 

60 [-1.265, -0.632, 0.0, 0.632, 1.265] 

61 """ 

62 # variables for calculation 

63 mu = mean(data) 

64 sigma = stdev(data) 

65 # standardize data 

66 return [round((x - mu) / (sigma), ndigits) for x in data]
